# 待办池（Backlog）

> 观察期（S1）内**不做**这些。每项写清楚：解决什么问题、为什么现在不做、什么条件下才启动。
> 启动时必须从阶段范围里换出一项（见 [stages/README.md](stages/README.md)）。

## 一、记忆能力

### B1. 日常记忆（episodic）

- **问题**：现在只记长期事实/偏好/规则；"最近在做什么"完全不记。用户问"我上周说要看的那本书叫啥"时无从回答。
- **为什么现在不做**：会让记忆量爆炸，且需要衰减与召回策略；S1 的效果判据还没跑完，不知道是否真的需要。
- **启动条件**：S1 判据 1（不用重复说）因为记不住日常而失败，或用户明确提出。
- **需要回答**：存什么粒度、多久衰减、是否进注入（倾向：只在相关召回时出现，永不进常驻）。

### B2. 语义去重

- **问题**："提交前先跑测试" 和 "以后提交前都跑一遍测试" 会存成两条。
- **为什么现在不做**：收益不明，且误合并比重复更糟。
- **启动条件**：`list` 里出现 ≥ 5 组明显同义条目。

### B3. 纠正 → 策略（RFC 0003 B 阶段）

- **问题**：纠正是收集了，但还没被用来提炼策略。
- **启动条件**：纠正证据 ≥ 20 条，且需要人工审批流程（pending → 确认）。

## 二、质量

### B4. affect 准确性

- **问题**："我不喜欢缩写" 被判为 `joy 0.63`；测试句"被老板批评"被判 `none`。
- **为什么现在不做**：不影响记忆闭环；需要一批标注样本才能定量。
- **启动条件**：收集 ≥ 20 句带人工标注的样本。

### B5. 规则抽取的疑问句之外的其他误报

- **问题**：本次修了疑问句；仍可能有命令/闲聊被误抽。
- **启动条件**：观察期出现第二类误报。

## 三、体验

### B6. 审计留痕（原 N2）

- **问题**：`list` 看不到每条记忆是哪条规则/哪次模型调用写的。
- **启动条件**：S1 结束后按路线图排序。

### B7. 长会话提醒（原 N3）

- **问题**：长会话里没有归档提醒。
- **启动条件**：同上。

### B8. 测试样本的代码支持

- **问题**：目前靠 `测试：` 前缀约定，靠自己遵守；程序不认识。
- **启动条件**：观察期因为测试句污染统计 ≥ 2 次。
