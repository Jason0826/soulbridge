## 完成定义（DoD）

全部满足才算完成，缺一条都不算：

| # | 判据 | 怎么验 |
|---|---|---|
| 1 | 每轮最多一次相关注入，无重复 | 日志中同一 turn 的 `prestep: inject` 计数 ≤ 1 |
| 2 | 注入内容不被回写成记忆 | 日志不出现 `source=memory-context` 的 `observe` |
| 3 | 相关性可接受 | 抽查 10 次提问，注入内容与问题相关 ≥ 8 次 |
| 4 | 蒸馏失败率低 | `llm=failed` 占比 < 5% |
| 5 | 迁移不会因备份丢数据 | schema 升级前后 `PRAGMA integrity_check` 通过，备份可独立打开 |
