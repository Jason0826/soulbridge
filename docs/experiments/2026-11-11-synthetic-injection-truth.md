**注入方式（冻结语义）**：不重演抽取——把 harness.db 里已通过 §4 的 `book-synth` 行**整体复制**进生产库 xiaoling（同 id、soul_id 改写、连带 turn/slot），复制出的全部行 id 写入 `synthetic-injected-ids.json`。读侧考的是"送达"，库内容必须是写侧已验证的状态，不引入模型方差。

## 6. 污染封死（三条协议）

| # | 协议 | 封死什么 |

| **A** | 故事细节、题面、答案键**只存在于文件**（本文档 + 故事文件），不出现在任何会话对话——**包括本开发会话** | 对话内容会被抽进 facts、存进 turn_pairs → 测试会话答对了也分不清来源（假送达） |
