# ADR 0026：生命感分层与降级

- 状态：Accepted
- 日期：2026-10-30
- 相关：ADR 0001（只做 soul 层）、ADR 0007（接入阶梯）、`thesis.md` P3（跨宿主）、`briefs/0006`、`briefs/0009`

## 背景

同一宿主（DSH）上出现了另一个实现 `digital-life-core`：它用 `agent/request` 改采样温度、
用 `agent.followup` 自主唤醒、用 `ctx.interval` 做离线梦境、用器官宿主热装记忆。已核实
这些能力是真的（不是 README 宣称）。它证明了"在 DSH 上做生命感"是可行的。

这带来一个诱惑：**为了"更像活着"，把 soulbridge 往宿主深处绑。**

但 thesis 的 P3 是"同一 soul 跨宿主"，ADR 0001 明确不做 runtime。全绑 DSH = P3 直接失效。

ADR 0007 定过"接入阶梯"（T0–T3），但它回答的是"**怎么接进去**"，没回答"
**宿主能力不同时，生命感怎么分级、怎么退化**"。

## 备选

1. **做到最深**：能量、激素、唤醒、器官全上。生命感最强，但绑死宿主，P3 作废。
2. **只做最浅**：只做记忆与注入。跨宿主成立，但产品太素，且把"人格"缩成了"检索"。
3. **分层 + 降级**：定义能力层，soul 只依赖最低层，高层的收益按宿主能力自动取舍。

## 决定

选 3。定义五层：

| 层 | 需要宿主提供 | 提供什么生命感 | 正确性前提？ |
|---|---|---|---|
| **L0 数据** | 无 | 记忆 / 情绪状态 / 缺口 / 疤痕 / 时间感 | ✅ 是 |
| **L1 注入** | 能改提示词（systemPrompt 或 pre-step） | 措辞、排序、注意力倾斜 | ✅ 是 |
| **L2 采样** | 请求前置钩子（DSH 的 `agent/request`） | 情绪改 temperature / 插在最前 | ❌ 加成 |
| **L3 生命周期** | 定时器与主动开口（`interval` / `followup`） | 自主唤醒、离线梦境、作息 | ❌ 加成 |
| **L4 器官** | 插件 ABI / 热装载 | 记忆/情绪成为可插拔器官 | ❌ 加成 |

### 三条不可让渡

1. **L0 必须可导出**。状态导不出去，就不是跨宿主，只是"另一个本地方案"。
2. **L2+ 只能是增强**。任何"没有 L2 就不成立"的设计一律打回——那是把宿主当成前提。
3. **降级必须可观测**。当前跑在几档、缺了哪些能力，要写进日志和状态文件，不能悄悄退化。

### 降级表

| 能力缺失 | 退到 | 用户能感觉到什么 |
|---|---|---|
| 没有 `agent/request` | 情绪只改注入文本与排序（L1） | 语气还在，"采样更谨慎"没了 |
| 没有 `followup` | 不主动开口（L1） | 不会主动找你 |
| 没有定时器 | 无梦境、无作息（L1） | 只在对话时存在 |
| 什么都没有 | 只做 L0 数据 + 手工导出 | 只剩"它记得我" |

### 现有设计落位

- `briefs/0009` 的缺口 / 疤痕 / 时间感 → **L0**（纯数据，已设计）
- `briefs/0006` 的情绪动力学 → **L1 兜底、L2 加强**（改采样是加分项）
- 检索与注入 → **L1**（唯一必须做好的那层）

## 后果

**正面**

- 每层可独立验证、独立发布；L0/L1 今天就能端到端验
- 有明确的"不做什么"边界：不会为了生命感把架构绑死
- 对宿主能力差异有了统一说法，不用每次重新讨论

**负面**

- 同一套规则要维护"有 L2 / 无 L2"两条路径，测试面变大
- 大部分宿主永远停在 L1，L2+ 的投入只服务 DSH
- 分层本身容易被误读成"我们不思进取"

**需要持续验证**

- L2（改采样温度）到底带来多少可测收益？如果收益接近于零，应主动砍掉，而不是留着炫技
- 反面样本：`digital-life-core` 在 L0 上比我们薄（跨会话记忆靠自写器官补），
  在 L2/L3 上比我们厚。**两种厚度的取舍是否真的成立，只能靠 P3 实验回答。**
