# ADR 0008：transcript 只读 user turn 与 assistant 最终回复

- 状态：**Accepted**（2026-10-27 确认）
- 相关：ADR 0007（T1 摄取）、隐私

## 背景

`reflect()` 需要一段会话作为素材。可选项从"只要用户说了什么"到"包括每一次工具调用与结果"。

本机实测：DSH 单个会话文件已达 1.5MB（含工具输出与推理片段），全量读取会让一次反思的输入体积高出一个数量级，同时显著扩大隐私面。

## 备选

1. **仅 user turn + assistant 最终回复**：最小可用集。
2. 全量（含工具调用、工具结果、thinking）。
3. 仅 user turn：反思会失去"我答了什么"的上下文，容易误判"用户为什么不满"。

## 决定

选 1。

- **读**：所有 `user` 消息；每条 assistant 消息的最终文本回复。
- **跳过**：工具调用与结果、`thinking/reasoning` 段、附件与文件正文、系统提示。
- **绝不落盘原文**：反思产物只保存抽取后的记忆条目与情绪增量。

## 后果

**正面**

- 反思输入体积可控（约降低一个数量级）；
- 隐私面最小：不含代码内容、命令输出、密钥误写；
- 与"记忆=人格，不是日志"的定位一致。

**负面**

- 无法分析"工具执行失败"导致的用户不满——这类信号只能靠显式纠正文本捕获；
- 若未来要做"工具使用质量"评估，需要另行实现，且必须重新走隐私评审。

**触发重新评估的条件**

- 单臂评估显示 `no_repeat` 指标几乎不动，且失败案例集中在"工具结果"相关场景。
