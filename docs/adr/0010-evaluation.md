# ADR 0010：v0.1 先做单臂评估，四臂实验留到 P3

- 状态：**Accepted**（2026-10-27 确认）
- 相关：`docs/thesis.md`（P1 预测）、ADR 0009

## 背景

thesis 的核心预测（人格型记忆的收益不随上下文窗口增大而消失）需要四臂实验才能严格检验：无记忆 / 全量上下文 / 事实检索 / 人格层，在 8k–1M 三档上下文下对比。

那套实验约需三周，且依赖稳定实现。若一开始就做，会拖住"能不能用"这个更基础的问题。

## 备选

1. **v0.1 单臂前后对比**（有 soul / 无 soul），3 天出方向。
2. 直接上四臂实验。
3. 不做量化，只看主观感受。

## 决定

选 1。

**v0.1 指标（按优先级）**

| 指标 | 定义 | 判据 |
|---|---|---|
| 重复提问/重复犯错率（主） | 同类问题或同类纠正，30 天内是否复发 | 有 soul 组显著低于无 soul 组 |
| 风格一致性 | 同一 soul 跨会话的表达/判断是否连贯 | 人工抽样 + 盲评，不下硬阈值 |
| 任务成功率（护栏） | 常规完成率 | 不得下降 |
| 成本 | 每任务 token 与延迟 | 记录即可，暂不设阈值 |

**P3 再做四臂**，含 8k / 128k / 1M 三档，用于检验 thesis 的 P1 预测。

## 后果

**正面**

- 三天就能回答"这东西有没有用"，避免在未验证的假设上堆功能；
- 单臂评估的实现（ON/OFF 双 soul、case 集）可直接复用到四臂。

**负面**

- 单臂无法区分"人格记忆"与"多一段上下文"的贡献——这正是四臂要解决的问题；
- 结论在 P3 之前只能表述为"有效果"，不能表述为"因为人格"。

**红线**

- 任何对外表述都必须注明"单臂、非对照实验"，不得暗示因果。
