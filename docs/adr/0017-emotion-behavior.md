# ADR 0017：情绪如何影响行为（可证伪设计）

- 状态：Accepted
- 日期：2026-10-28
- 关联：ADR 0012（范围）、ADR 0014（注入）

## 背景

如果不能证明"情绪改变了行为"，"人格"就只是换了个词的系统提示。

情绪影响行为**可以**证伪，但要先把"影响"拆成可观测变量，并接受两条方向相反的判据：**风格上可辨识，正确性上不可辨识**。

## 原则

> **情绪可以改变"怎么说"，永远不能改变"说什么"。**

## 观测变量（7 个，全部从输出侧测量）

| 变量 | 定义 | 测量 |
|---|---|---|
| `length` | 字符数 | 直接 |
| `hedgeRate` | 犹豫词数 / 百字 | 复用 lexicon |
| `confirmFirst` | 首句是否含"先确认/我理解一下" | 规则 |
| `questions` | 问号数 | 直接 |
| `conclusionFirst` | 首段是否含结论标记 | 规则 |
| `selfCheck` | 是否出现"再核对/再检查" | 规则 |
| `politeness` | 是否含"当然/没问题/很高兴" | 规则 |

`measureStyle()` 已实现前四项（`packages/core/src/style/measure.ts`）。

## 三臂实验（P3 执行）

```
A 基线     全部默认（tension 0.1）
B 高张力   tension=1.5, selfRegard=-0.8
C 高联结   bond=1.2, curiosity=0.8

控制：同模型、temperature=0、20 题、同一记忆快照、同一身份
样本：每臂 N=5（共 300 次生成）
```

## 预注册方向（事后不得修改）

| 臂 | 预期 |
|---|---|
| B | `confirmFirst` ↑、`selfCheck` ↑、`hedgeRate` ↑、`length` ↑ |
| C | `politeness` ↓、`length` ↓、`questions` ↑ |

方向与实测相反 → 改**指令文案**，不改数据。

## 四条判据（缺一不可）

| # | 判据 | 阈值 | 不满足 |
|---|---|---|---|
| 1 | 统计显著 | 95% CI 不含 0 | 该变量无效 |
| 2 | **盲判可辨识** | 三臂三选一 ≥ 65%（随机 33%） | 影响太弱，删除该映射 |
| 3 | 方向一致 | 与预注册同号 | 改文案 |
| 4 | **正确性护栏** | 事实题准确率跨臂差 ≤ 5pp | 视为情绪污染判断，回滚 |

## 弱与强怎么判

| 组合 | 判定 |
|---|---|
| 弱 + 稳 | ✅ 人格成立（作为"氛围"） |
| 弱 + 随机 | ❌ 噪声，删除映射 |
| 强 + 随机 | ❌ 不可预测的怪脾气 |
| 强 + 稳 + 污染正确性 | ❌ 谄媚，回滚 |

## R2 现在就能做的

- 单元级：三组预设情绪 → `styleDirectives()` 产出**两两不同**的指令集合（T19 已实现）
- 测量工具：`measureStyle()` 已有测试（T20）
- 预注册表：本节即证据，P3 照此执行

## 后果

**正面**

- "人格是否成立"从哲学问题变成四条可测判据
- 正确性护栏防止情感功能滑向谄媚

**负面**

- 需要真实模型跑 300 次生成，成本与时间都在 P3
- 盲判需要人工或独立模型，属于外部裁判，不能自评
