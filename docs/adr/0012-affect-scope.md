# ADR 0012：affect 的作用范围

- 状态：Accepted
- 日期：2026-10-28
- 关联：ADR 0017、ADR 0018

## 背景

情感信号有三条可能的用途：改措辞、改记忆权重、改情绪状态。三者的风险完全不同：

- 改措辞：错了只是语气不对；
- 改记忆权重：错了会污染长期记忆；
- 改情绪：错了会自我强化（用户生气 → 我更紧张 → 更糟的回答 → 用户更生气）。

## 备选

1. 三条全上：一次到位，但都是未经验证的假设。
2. **只上第一条 + 采样**：最小风险，先攒数据。
3. 只采样不消费：最保守，但没有任何产品价值。

## 决定

选 2。

- **允许**：affect → 风格指令（白名单）、affect → 采样表
- **禁止**：affect → `Emotion` 写路径、affect → `importance` / `vividness`、affect → 事实判断
- 被禁止的两条要解禁，必须先满足 ADR 0017 的四条判据 + 至少一个月的真实采样

## 后果

**正面**

- 风险最低：即使分析全错，最坏结果是少一句提示或语气偏差
- 采样表为 P3 提供归因数据（`analyzer` 字段能区分规则还是模型）

**负面**

- v0 的 affect 只影响"怎么说"，产品感知弱
- 不做情绪桥接，"共情"能力有限

**解禁条件（写死）**

| 机制 | 解禁条件 |
|---|---|
| affect → Emotion | ADR 0017 四条判据全过，且 `sycophancy_guard` 不退化 |
| affect → 记忆权重 | 成长实验（ADR 0018）显示加权记忆提升 `repeatCorrection`，且不增加 `memoryPrecision` 劣化 |
