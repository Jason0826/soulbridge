# ADR 0013：词库的来源与许可

- 状态：Accepted
- 日期：2026-10-28

## 背景

参考项目 expression-trainer（MIT）的情感词库标注为"基于大连理工 7 大类情感词库精选版"。**代码的 MIT 不能传染到词表**：DUTIR 是学术授权资源，直接复制其词条会让我们背上无法履行的许可义务。

同时，情感分类的**结构**（7 类、强度 1–9、极性）是公开的学术共识，不受版权保护。

## 备选

1. 直接复制那 650 词：开箱准确率最高，许可风险不可接受。
2. **只采纳结构，自写种子表**：合法，召回略低。
3. 不内置任何词表，强制用户提供：合法但安装后不可用。

## 决定

选 2，并加一条扩展路径：

- 仓库内置 `seed-lexicon.ts`：约 90 个词条，**为本项目撰写**，随仓库以 MIT 发布
- 支持外部词库：`lexicon.v1.json`（格式见 `spec/affect.v0.md`），由用户通过 `--lexicon` 或 `SOULBRIDGE_AFFECT_LEXICON` 提供
- **用户导入的词表由用户自行承担许可责任**，文档必须写明

## 后果

**正面**

- 项目可以合法开源
- 用户想用更全的词表时有一条干净的路

**负面**

- 开箱召回弱于参考项目
- 需要维护"种子表 vs 外部词表"两套加载路径（已由 `validateLexicon` 覆盖）

**红线**

- 任何 PR 若直接粘贴第三方词表，一律拒绝
- 新增种子词受 ADR 0016 的预算限制（≤120）
