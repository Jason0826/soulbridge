# ADR 0037：属性闸——同槽位状态链在写入侧互撤

- 状态：**Proposed**（2026-11-18 起草，待用户接受；接受前机制已在代码里，见「验证」）
- 日期：2026-11-18
- 关联：[state.md 18:50 发现 A](../state.md)（由来与数据）· [ADR 0029](0029-extraction-is-the-models-job.md)（抽取归模型，本 ADR 只加声明与闸）· [ADR 0031](0031-model-dependency-acceptance.md)（模型环节四关）· 规则 31（判断归模型，形态归代码）· 规则 40（多语句写入是一个事务）

## 背景

11-18 辨别样本终判发现：库里同一个属性的新旧值**同时 active**，共 4 组实例——

```
ActiveSiteKey   Douban / nodejs_wogg / Wogg 三值并存（只撤了中间的 woWogg）
ADR 0036        「仍为 Proposed」与「已转 Accepted」并存
core 版本       0.0.26 与 0.0.128 并存
cardTimeoutMs   同一变更写了两遍，两条都活着
```

根因是既有取代机制（`操作=取代 <id>`）的两个前提都靠不住：

1. **模型只能撤它看得见的旧行**——18:50 审计的 38 对里，16 对旧值根本不在抽取池（池未呈上），模型无从命名 target；
2. **看得见也要模型当场判成矛盾**——8 对在池仍漏判，jaccard + 临场判断对「值状态」这种天生互斥的关系精度不够（发现 B 同场证实：jaccard 网对格式句约半数误报）。

值状态（"X 现在是 / 改成了 Y"）的互斥**不是语义判断，是声明的定义**：说了"当前值"，旧值就不再是当前值。这个判断不需要读句子内容，所以不该留给模型临场发挥。

## 决策

### 1. 模型声明键，代码执行互斥（规则 31）

事实行槽位可写 **`属性=<名字>`**（`属性=ActiveSiteKey`、`属性=ADR状态`、`属性=版本`），声明"这条事实是该属性此刻的值"。

- **模型**：只有它知道一句话关于什么——起属性名、判断"这是值状态不是事件"，都是语义判断；
- **代码**：`commitDrafts` 写入后一道闸——同 soul/user/holder、同属性、还 active 的旧事实全部 `supersedeFact` 退休，**不管旧值在不在抽取池、不管模型有没有判出矛盾**。

### 2. 闸的边界（防误撤的四条）

- 只对 **active** 的新事实开火：`lesson`/`rule` 落库即 candidate，候选不是事实，不退休现值；
- 属性值按 **text 精确匹配**，不做模糊、不猜数字（语法不推语义，规则 8）；
- 退休记进 **`CommitResult.attributeRetired`**，与 `actions` 分开——actions 数的是模型的意图，attributeRetired 数的是闸自己的决定，混在一起日志就分不清"谁撤的"（规则 18）；
- 作用域 = 同 holder：我认知里的属性值不撤用户视角的同名属性值。

### 3. 解析器尾段合并（否则闸会静默失效）

事实行尾部的非键值段**原来只取第一段、后续静默丢弃**：模型把 `属性=` 排第二段时闸永远拿不到键，发现 A 从解析器这侧原样复发且无日志（规则 11/18）。改为全部并入槽位文本。

### 4. 提示词三处（模型得知道要写）

`terms` 给属性的定义与判据（"X 现在是____"读得通才写）、`rules` 给操作指令（值状态必须写属性，旧值不在 `<known-facts>` 里也撤得掉）、`examples` 给一行示例。提示词体积上限 5900→6500（prompts.test.ts 有账：+545 字符，砍掉任何一段模型都会漏写）。

## 后果

- **覆盖面**：只对带属性声明的事实生效。存量无声明的旧行不会被新事实撤——本次 8 对已按 18:50 审计结论**手工修复**（显式 id 对 + 语句前缀断言 + 前后对照，原始行全部保留）；新对新从装机重启后开始生效。
- **模型要起对名字**：`属性=版本` 同时想表达 core 与插件版本就会误撤——属性名是模型的语义责任，提示词已写"属性是那件事的名字，不是这一句的措辞"，误撤属可发现错误（attributeRetired 可查）。
- **非原子**：与既有 `操作=取代` 同一条路（先写新行、再逐条撤，每步自己抛错）；极端情况下部分撤会留到下一次同属性写入补撤——链总是向"只剩当前值"收敛。
- **发现 B 未处理**（jaccard 0.30 网对格式句精度低）：属筛查侧，与本决策正交，待拍是否立债。
