# ADR 0018：成长如何被证明（可证伪设计）

- 状态：Accepted
- 日期：2026-10-28
- 关联：ADR 0010（评估口径）、ADR 0017（情绪）

## 定义

> 同一用户、同类任务、跨会话，**同类错误的复发率**与**重复提供已知信息的次数**随时间下降，且记忆被正确使用——而不是靠多塞上下文或减少输出。

## 与情绪的差别

| | 情绪 → 行为 | 成长 → 行为 |
|---|---|---|
| 时间尺度 | 单轮 | 4 周以上 |
| 对照 | 三臂（预设） | 双 soul（有/无记忆） |
| 混杂 | 无 | 用户在学、任务在变、模型迭代 |
| 特有陷阱 | 干扰事实判断 | 靠少做事/多塞上下文假装变好 |

## 观测变量（5 个）

| 变量 | 定义 |
|---|---|
| `repeatCorrection`（主） | 同类纠正 30 天内复发率 |
| `repeatInfo` | 用户重复提供已知信息的次数 |
| `memoryPrecision` | 注入记忆后被后续证伪的比例（错记率） |
| `injectVolume`（护栏） | 每次注入的 token 数 |
| `taskCompletion`（护栏） | 任务完成率 |

## 设计

```
对照：A = 有记忆与反思；B = 同模型、每次空白
对象：同一用户、同类任务
周期：4 周，每 2 天一次采集
外加：停用 2 周后做一次回退测试
```

## 六条判据

| # | 判据 | 阈值 |
|---|---|---|
| 1 | 斜率 | A 的 `repeatCorrection` 斜率为负且显著 |
| 2 | 差距 | A 相对 B 的下降 ≥ 20%（相对值） |
| 3 | 可感知 | 第 4 周会话盲评为"更懂我" ≥ 65% |
| 4 | 完成率护栏 | 不降（±5pp） |
| 5 | 注量护栏 | `injectVolume` 不涨 |
| 6 | **回退测试** | 停用 2 周后重复率仍低于基线，且保留 ≥50% 的降幅 |

## 弱与强怎么判

| 组合 | 判定 |
|---|---|
| 弱 + 可保留 | ✅ 伙伴 |
| 强但一停就回落 | ❌ 只是上下文残留 |
| 强但靠少做事 | ❌ 作弊 |

## 与情绪的分工（写死）

- 纠正会推高 `tension`，`tension` 会改变措辞（ADR 0017）
- **但情绪不参与"是否学到策略"**：`reflect()` 的策略抽取只看纠正内容，不看情绪值

## R2 的义务

不做实验，但采样必须能支撑它：

- `affect_samples` 带 `analyzer` / `confidence` / `at`
- `context()` 已记录注入的 `used` 记忆 id
- 这两样是成长实验的原始数据，R2 不能省
