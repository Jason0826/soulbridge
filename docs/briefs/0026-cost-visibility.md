# 0026 成本可见：每轮请求与每日账单

- 状态：已实施（2026-11-04）
- 触发：用户问「一百元只用了四天，你能看到我们的用量数据吗」。
- 上游：`docs/state.md` 接手须知「下一步 1) 每轮成本日志 2) 每日账单脚本」。

## 一、问题（实测）

```
平台导出一行 = 一天：金额 / 请求 / 三类 token
11/01–11/04  ¥100.22 · 6,028 次请求 · 78% 的钱花在输入（缓存命中 56% / 未命中 22%）
一次会话 387 轮，单轮最多 108 次请求（trace.jsonl，turn 406），平均 18 次
```

两个缺口：

| 缺口 | 后果 |
|---|---|
| 只有天，没有轮 | 「刚才那轮为什么花了这么多」答不出来；花大钱的少数长轮被平均掉 |
| 插件自己的调用不在任何日志里 | 抽取/归纳/分类的请求与 token 没有落点，用户看到的数和实际支出对不上 |

## 二、决定

**分工：钱只在账单脚本里算，轮只在插件里记。**

| 谁 | 记什么 | 权威 |
|---|---|---|
| 插件 | 每轮一条 `turn-cost`：请求数、步骤数、失败尝试、插件自己调用、四类 token、耗时、结束原因 | DSH 事件流（`step/start` / `assistant/attempt` / `assistant/message.usage`） |
| `scripts/billing.mjs` | 每天：金额、请求、三类 token、按单价重算的复核值 | 平台导出 CSV（唯一金额来源） |

插件**不估金额**：价目有峰谷两档（导出里同一 token 类出现两个单价），会变；抄一份进代码就是第二份真相。

### 2.1 请求数怎么数

```
requests = steps（step/start，一次模型调用） + failed（assistant/attempt，重试且没出消息）
         + plugin（插件自己的模型调用）
```

实测 `step/start` 6782 / `assistant/message` 6774 / `step/end` 6769，失败尝试很少但确实存在，所以要单列。

### 2.2 阈值

```
requests ≥ 30 → plugin.log 多打一行（实测 401 轮里 27 轮达到，约 9 行/天）
每一轮 → trace.jsonl 一条 turn-cost（约 34 条/天，可被 quality.mjs 读）
```

## 三、边界（不做什么）

| 不做 | 为什么 |
|---|---|
| 把子代理的请求滚到父轮上 | 事件流里没有父子关系；滚错比不滚更坏。子代理各自开一个会话，各自一条记录 |
| 在插件里算金额 | 价目会变，且峰谷两档；金额只从平台 CSV 来 |
| 超预算告警 | 没有预算定义。先有数据，再有阈值 |
| 动抽取/归纳的调用次数 | 那是 0024 §3 的调用预算问题，不是观测问题 |
| 给「每轮」加 UI | 现在的读者是 `plugin.log` 和 `trace.jsonl`，先够用 |

## 四、成功判据（可执行）

```
node --test test/turn-cost.test.mjs            → 6 条全过（计数 / 阈值 / 上限淘汰 / 插件调用归属 / 空轮不写 / 会话隔离）
node scripts/billing.mjs                       → 11/01–11/04 合计与平台一致；按单价重算与账单差额 ≤1%
node scripts/quality.mjs --days 7              → 仍能算出四个比率（turn-cost 记录不干扰）
trace.jsonl                                   → 出现 "event":"turn-cost"，且 top 轮 requests 与导出量级一致
```

## 五、已知限制（写在这里，免得以后当成 bug）

- `plugin` 那一列按「最近一个收到事件的会话」归属；子代理会话同时开着时可能记到子代理头上。数字小（今天 41 次插件调用 / 598 次请求），先接受。
- 崩溃或重启导致的未结束轮次没有记录；同一个会话再来一轮时，上一条会以 `open:true` 补写。
- 导出 CSV 的 `request_count` 与插件计数口径不同（前者含所有进程、所有 key；后者只含 DSH 事件流里看到的），核对时看差额，不要求相等。

## 六、开放问题

1. 子代理的请求要不要按父会话滚起来？——需要 DSH 暴露会话谱系，事件流现在没有。
2. 要不要把「每轮金额」也写进 trace？——需要先定价目来源（配置还是导出回填），本轮不做。
