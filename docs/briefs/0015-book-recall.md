## 1. 要验证什么

**记忆层能不能只靠库里的事实，回答一个它在"读"的时候就再也看不到原文的世界。**

这是事实层的端到端验收，覆盖：实体识别与消解、事件与时间、状态变化、人物关系、跨会话召回。

## 2. 设计

```
读：一本书 → 切段 → 脚本批量喂（一段一次抽取调用，确定性、可复跑）→ 写入，原文不注入
问：新开真会话 → 问人物/事件/关系 → 只靠记忆回答
判：逐题对照原文，分三种结果
```

**喂入方式（11-11 定）**：写入侧走**脚本 harness**（`scripts/book-feed.mjs`；零代码兜底 = 会话贴段，
但慢、贵、会撑大会话触发压缩，只作备选）；**提问必须真会话**——那半测的就是检索 + 注入。
**段落带信封喂入**：`下面这段《阿Q正传》的原文，把里面关于人物和事件的事实抽取出来：`——
首跑实测裸小说原文 **19/25 段模型答「无」**（生产提示词 role 写明"只从对话里抽取"，
前提是对话）；信封 = 模拟用户贴书时会说的话，**提示词本体一行不改**。
原始回复落 `~/.soulbridge/book-feed-raw.log`（首跑没落，多花了一次探针才分清"模型说无"和"解析吃掉"）。

**关键约束**：问的时候不允许把原文放进上下文。否则测的是长上下文，不是记忆。

## 3. 选书

| 项 | 选择 | 理由 |
|---|---|---|
| 书 | 《阿Q正传》（约 2 万字，公版） | 人物密度高（阿Q、赵太爷、吴妈、小D、王胡）、事件成链、有状态变化（从雇工到被枪毙）、关系复杂 |
| 规模 | 首轮只跑这一篇 | 跑通再上长篇 |
| 切段 | 800–1200 字/段，约 20–25 段 | 与注入预算无关，是为了抽取质量 |

## 4. 问题集（30 题）

| 类别 | 数量 | 例子 |
|---|---|---|
| **人物** | 10 | 阿Q 是谁？他和赵太爷什么关系？吴妈在他生活里是什么角色？ |
| **事件** | 10 | 阿Q 为什么被打？他最后怎么了？"革命"那件事他怎么参与的？ |
| **关系** | 10 | 谁看不起阿Q？他和谁起过冲突？为什么小D被他瞧不起？ |

每题标注：**答案出处段落**（用于判定是否可追溯）。

## 5. 判分

| 结果 | 定义 |
|---|---|
| **对** | 关键事实与人名正确，且不冲突于原文 |
| **错** | 与原文矛盾 |
| **不知道** | 明确说不知道，或答案不含关键信息 |
| **编造** | 给出的细节在原文不存在（无论听起来多合理）——**单独统计** |

## 6. 指标与门槛

| 指标 | 门槛 | 说明 |
|---|---|---|
| 人物 recall | ≥ 60% | 书的角色是有限的枚举，可人工定真值 |
| 事件 recall | ≥ 50% | |
| 关系 recall | ≥ 50% | |
| **编造率** | **≤ 10%** | 硬门槛：宁可不知道，不可编 |
| 可追溯率 | ≥ 80% | 答案能指回具体事实/段落 |
| **合并观察（写入侧）** | 已知重复对出 `sup`/`upd` 而非 `add` | 用 `action=` 计数（11-11 上线）；这是判据 3「没记岔」**辨别样本**的来源——同一事实跨章再现时，看模型合并还是重写 |

任一项不达标 → 不进入 MVP2。

## 7. 成本

- 抽取：约 25 段 × 1 次 LLM = 25 次调用
- 判分：30 题 × 1 次裁判 = 30 次（可用人工抽检替代）
- 单次实验约 50–60 次调用，可接受

## 8. 反作弊

1. 提问会话**不注入原文**，只注入记忆层检索结果
2. 题库**与真值表**（角色表 / 事件表 / 各指标分母口径）**跑之前落盘**，跑之后不调整——
   分母口径不落盘就复核不了（11-11「42 条发布状态」的教训：9 个候选定义都对不上原数）
3. 判分用独立裁判（人工或另一模型），自评不算
4. 编造单独统计，不能被"答得多"稀释

## 9. 与主线的顺序

```
1. ✅ entities / facts / fact_slots / gaps 落库（11-11：1402 条 active，生产在跑）
2. ✅ 抽取器上线（LLM 为主、代码兜底；候选池四层 + pool=/action= 观测）
3. ✅ 喂入 harness（scripts/book-feed.mjs，11-11 跑通：25/25 段、253 事实）
4. ✅ 真值表 + 题库落盘（2026-11-11-book-recall-truth.md，提交早于喂入）
5. ⬜ 跑第一遍提问（30 题独立新会话——操作方式定案后开问）
6. ⬜ 调抽取/召回 → 再跑，看变化
```

## 10. 明确不做的

- 不做全文问答（那是长上下文，不是记忆）
- 不做多本书同时（一次一本书，变量单一）
- 不追求高 recall 掩盖编造——**编造率是一票否决**
