# 0021 画像维度：定义、来源与准入

- 状态：Draft
- 日期：2026-11-02
- 关联：[ADR 0033](../adr/0033-rules-profile-memory.md)（规则/画像/记忆三层）

## 为什么需要这份文档

画像曾经是"合并后的几条判断"，没有维度。结果是工作类内容占满 6/9，情绪、生活、边界全空——**一个只懂工作的画像，是同事，不是伴。**

维度解决两件事：

1. **注入时机**：工作的事带工作视角，累的时候带情绪视角；
2. **完整性可测**：覆盖率能指出哪一维是空的，而不是靠感觉。

## 七个维度与文献对应

| 维度 | 定义 | 文献依据 | 强度 |
|---|---|---|---|
| 价值观 | 超越具体情境、值得追求的目标 | Schwartz 基本价值观（10 值，环形结构，有跨文化元分析） | 强 |
| 工作方式 | 面对任务时的稳定做法 | O*NET Work Styles / 大五尽责性面向 | 中 |
| 沟通偏好 | 希望信息以什么形式、什么节奏出现 | 人际环的温暖-支配 + 外向/宜人面向 | 中 |
| 情绪 | 对具体事件的感受与强度 | 核心情感（效价 × 唤醒）/ PANAS | 强 |
| 人际关系 | 与特定人的位置和距离 | 人际环（Wiggins）+ 依恋类型 | 中 |
| 生活兴趣 | 自愿投入时间的事 | Holland RIASEC | 强 |
| 边界 | 明确说过的"不要" | **无公认分类学**，临床"个人边界"概念 | **弱** |

**声明**：七个维度是**产品切分**（按消费场景：关心近况、别踩雷、协作、聊得来），不是人格理论的完备集。完备集会更大（NEO-PI-R 有 30 个面向），也会让注入臃肿。

## 每条维度的准入定义

写进合并 prompt，模型按此判断"什么算一条"：

```
价值观:     "想把事做对"算；"这个接口用 POST"不算
工作方式:   "先验证再动手"算；"这次改了 A 文件"不算
沟通偏好:   "整轮对话当整体"算
情绪:       "被反复确认会烦"算；"今天天气"不算
人际关系:   "她最近压力大"算
生活兴趣:   "喜欢爬山"算
边界:       必须贴着原话，不许概括（无分类学，概括就是编）
```

## 完整性的度量

```
维度覆盖率 = 有内容的维度数 / 7
可追溯率   = 有 ≥1 个来源 id 的画像行数 / 总行数
```

覆盖率说明"结构上哪里空着"；可追溯率说明"是不是算命"。

**当前（2026-11-02）**：

```
active profile: 9 行
  ✅ 价值观 1 · 工作方式 5 · 沟通偏好 2 · 人际关系 1
  ❌ 情绪 0 · 生活兴趣 0 · 边界 0
dimension coverage: 4/7
```

**这个 4/7 就是"人格不完整"的具体形状**，不是感觉。

## 覆盖为空时怎么办

**不补空话。** 空的维度表示"还没发生能构成它的事件"。正确的下一步是：

- 真实对话里出现生活/情绪/边界内容 → 抽取 → 合并进对应维度
- 在此之前，报告里红着，比编一条"用户重视生活品质"诚实

## 声明与验收

1. 合并输出每行必须带合法维度；非法 → 拒绝该行
2. 注入：价值观与未标注的旧行常驻；其余按消息命中的维度注入
3. 覆盖率脚本每次能跑出上面那张表
4. **验收**：同一份来源合并后，覆盖率不低于合并前（合并不能吞掉维度）
