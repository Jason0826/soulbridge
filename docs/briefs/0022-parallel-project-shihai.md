## 一、对方在做什么

一个陪伴型 AI 的长期记忆系统，三个机制：

| 机制 | 负责什么 |
|---|---|
| 识海 | 哪些记忆现在**可能**被想起（潜伏 + 竞争） |
| 星光 | 哪些记忆**值得**真正进入意识（闸门） |
| 心流 | 真正拿来思考的工作区（槽位 2/4） |

记忆单元不是一句话，而是带属性的**事件**：事件内容、时间、人物、场景、情绪、意义、强度、关系权重、可检索性、身份相关性。

## 三、机制对表（他们 vs 我们已有代码）

| 他们 | 我们 | 判断 |
|---|---|---|
| 潜伏、不参与思考 | facts/memories 状态机 + 注入预算 | 同构 |
| 十维记忆属性 | `fact_slots`：at/精度/holder/affect/recall/confidence/维度/来源 | 缺**场景、关系权重、身份相关性** |
| 激活值 = 内容×人物×情绪×时间×注意 | `scoring.ts` 加权和 0.35/0.25/0.20/0.15/0.05 | 我们已避开乘法脆性 |
| 衰减 e^(−λt)，情绪比细节久 | recency 半衰期 30 天 | 只有一条曲线 |
| 回忆即改写 | lastRecalledAt 重置 recency + recallCount | 我们只做"变重"，不做"重写" |
| 星光闸门 | 六种取数原语 + 预算 | 我们按"问什么"选，他们按"值得"选 |

## 五、不学他们三处

| 他们的做法 | 问题 |
|---|---|
| 乘法式激活值 | 任一因子≈0 就归零：相关但久远会被一票否决。加权和不会 |
| "当前注意资源"乘在每条上 | 全局常数，不改变排序；它该决定 k，不该进分母 |
| 时间衰减算两遍 | 时间因素 + e^(−λt) 双重惩罚 |

## 六、值得拿的三条（按可验证成本排序）

1. **关系四维**（safety/trust/closeness/tension）：字段在 `entities.attrs`，不用改 schema；直接服务场景 B。
2. **情绪残留比事实久**：我们已有 530 条 affect 样本，可离线验证。
3. **槽位化预算**（2/4，Cowan 4±1）：替代纯字符预算。

**不拿**：相似记忆互相抑制（无指标前加它=加幻觉）；"回忆即改写"的重写（没有版本化就是漂移）。

## 七、两条判断

**① 真正的分歧只有一条：回忆该不该改写记忆。**

他们选"会改写"（像人），我们选"原文不动、只改可达性"（可检查）。
我们要补"太像档案"这一课，不该靠引入失真，而是：

> **让失真的对象是"确信"和"精度"，不是原文。**

三月十四号的事，半年后记成"三月"，一年后记成"去年"：`at_precision` 降级、
`confidence` 随时间衰减，原文一个字不改。字段已经在，只是没人让它随时间变化。

**② 两者不在同一个市场。**

他们是**作品**（一个角色的记忆，绑在自己的运行时里），我们是**基础设施**（可插到任何 agent、
可导出、可继承）。作品靠体验取胜，基础设施靠可信取胜。照我们的定位，该学的是他们的体验细节，
不是换掉我们的契约。
