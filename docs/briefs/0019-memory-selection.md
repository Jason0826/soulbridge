# 需求说明：记忆的选择与遗忘（0019）

- 状态：Accepted（2026-11-02）
- 日期：2026-11-02
- 关联：[ADR 0032](../adr/0032-two-layers-of-memory.md)（两层与时间精度）、[0020 检索漏斗](./0020-retrieval-funnel.md)、[ADR 0031](../adr/0031-model-dependency-acceptance.md)
- 由来：用户指出——人的脑容量有限，AI 不是；硬盘够大就可以全留。**该衰减的是"被想起的概率"，不是数据。**

---

## 1. 决策

```
原文、事实、结论：全部保留，不因容量删除
衰减的：检索时可及性（相关 × 幂律衰减 × 复习加成）
删除只发生在三种情况：用户要求 / 隐私合规 / 数据损坏
```

依据：Tulving & Pearlstone (1966) 的区分——**可用性（还在不在）≠ 可及性（取不取得到）**；很多"遗忘"是检索失败，不是痕迹消失。
<https://www.sciencedirect.com/science/article/abs/pii/S0022537166800488>

## 2. 衰减用幂律，不用指数

Ebbinghaus 曲线常被画成指数，但原始数据拟合的是幂函数，后续分析也支持幂律优于指数（Wixted & Ebbesen 1991）；复现实验见 Murre & Dros 2015。

```
衰减 = 1 / sqrt(1 + 天数)          ← 幂律
练习 = 1 + 0.2 × ln(1 + 召回次数)   ← 被用过的不容易沉下去
排序 = 相关度 × 衰减 × 练习
```

被检索一次就记一次（`recall_count` / `last_recalled_at`，schema v8）——**这就是"复习"**。

## 3. 什么时候才真的删

| 触发 | 说明 |
|---|---|
| 用户明确要求 | 硬删除，导出契约也要遵守 |
| 隐私 / 合规 | 同上 |
| 数据损坏 / 重复 | 重建或合并 |

**容量不在列表里。** 存储不是约束，上下文窗口才是——那个问题在 0020 解决。

## 4. 时间未知不丢事实

见 [ADR 0032](../adr/0032-two-layers-of-memory.md)：确定发生但时间不明 → 写，标 `unknown`，开缺口。
**反例**：那条"和 a 吃火锅"没有日期，按"无时间即丢弃"处理，今天问"上次和 a 吃饭"就永远没有答案。

## 5. 度量

| 指标 | 口径 | 现状 |
|---|---|---|
| 无实体锚点率 | 无实体槽的事实 / 全部事实 | 0%（观察值，不是目标） |
| 召回强化率 | 有 recall_count 的事实 / 被注入过的事实 | 新上线 |
| 时间未知率 | `at` 为空的事实 / 世界层事实 | 77%（ADR 0032 要降） |

## 6. 验收

```
一周后问："上周下雨那天我在做什么？"
  能召回 → PASS（哪怕它从不进常规注入的 top-5，靠时间索引精确取）
  取不出 → FAIL
```

**关键差别：召回 ≠ 注入。** 权重可以近乎为零，但一问就能取出来。

## 7. 不承诺的事

**没有任何论文证明"幂律 + 复习对 AI 记忆系统最优"。** 这是借来的先验，不是验证过的结论。要做的是同一组问题对比 幂律 / 指数 / 不衰减，用数据定。
