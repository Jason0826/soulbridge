## 一、当前架构（一句话）

```
轮次（turns/steps）→ 事实（facts/fact_slots/entities/gaps）→ 线索（threads）→ 判断（规则 | 画像）
```

判断分三层（ADR 0033）：**规则**按触发注入、**画像**按维度注入、**记忆**按预算注入。
每层都有确定性闸门；模型只负责语义，失败有地板（ADR 0031）。
