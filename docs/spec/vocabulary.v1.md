# 词表 v1：五层、三态、一个名字

- 状态：**草案**（0024 第 2 步；定完才动 schema 与代码）
- 日期：2026-11-03
- 上级：[0024 从构想向下重排](../briefs/0024-soul-layer-rebuild.md)
- 原则：一个东西只有一个名字；阶段与类型不混在一个字段；每个名字必须有读者

## 1. 五层（只这五个）

| 层 | 名字 | 一句话 | 谁写入 | 谁读 |
|---|---|---|---|---|
| L0 | **轮** `turn` | 一次完整往返：用户 + 我的回复 + 步骤 | 代码 | 抽取、归纳、自省、导出 |
| L1 | **事实** `fact` | 关于某人/某物/某事的一句话，带时间与依据 | 模型 + 闸门 | 检索、归纳、画像 |
| L2 | **线索** `thread` | 可跨中断的话题章节 | 模型归属 | 归纳、handoff |
| L3 | **判断** `conclusion` | 对一条线索的一句话结论 + 证据 | 模型两阶段 | 注入、画像 |
| L4 | **画像** `profile` | 按维度合并的、关于"你"的判断（≤8 条） | 模型合并 | 每轮常驻 |
| L5 | **自我** `self` | 我的承诺/决定/教训 | 模型 + 纠正 | 注入、复核 |

> **自我层不是第六张表**：它是 `facts` 里 `holder=self` 且 `type_name ∈ {承诺, 决定, 教训}` 的那些行。
> 保留一个名字（自我层）是为了说清"谁读它"，不是为了建表。

## 2. 三态（只有三个）

```
raw       原始（不进任何注入；turns 与未加工片段属于这一态）
candidate 候选（可被检索到，但不常驻注入、不触发规则；待复现或确认）
active    生效（进注入、可触发规则、可影响语气）
retracted 撤回（保留行，任何注入都不读；撤回是生效的背面）
```

**规则**：状态只由代码写，不由模型写；模型只提供"证据"和"建议"。
**升级**：`raw → candidate` 由抽取/归纳产生；`candidate → active` 需满足该层的准入（见 §3）；`active → retracted` 由取代、纠正或过期触发。

## 3. 每层的准入（进入 active 的条件）

| 层 | active 条件 | 落选时 |
|---|---|---|
| 事实 | 有实体或时间锚；不是回声；不是对话动作 | 不写，记 `skipped` 原因 |
| 线索 | 归属成功（continue / fallback / new） | 不写，记原因 |
| 判断 | 证据 ≥2 且都可解析；验证阶段通过 | 留 `candidate`，不注入 |
| 画像 | 同维度 ≥2 条判断；合并后可追溯 | 不合并，保持原判断 |
| 自我 | 承诺/决定带依据轮次；教训带纠正轮次 | `candidate` |

## 4. 域：生活 / 工作

**不做成枚举，做成模型写的槽位**（ADR 0027：领域是语义，不是结构）。

```
槽位: 域=工作   或   域=生活   或   域=两者
```

- 代码只用它**过滤检索**（问工作的事时不把生活琐事排前面），不据此分支逻辑；
- 画像是跨域的（一个人既有工作方式也有生活习惯）；
- 没有"核心域"这回事：**核心由消费者决定，不由领域决定**——"她最近怎么样"是生活，"你答应过什么"是工作，两者都直接对应真实问句。

## 5. 情绪：状态，不是记忆

```
affect_samples   每次判定一条：dominant / intensity / valence / arousal / confidence
```

- **不写进 facts**（情绪不是"关于世界的事实"）；
- 它的消费者是**规则触发**，不是注入描述：

```
触发: affect=negative 且 intensity ≥ 6
动作: 第一条先承接；本轮不推进任务
```

- 观测：触发次数 / 随后 3 轮内被纠正次数 = 遵守率；没有这个数，规则就是 hope。

## 6. 名字对照（旧 → 新）

| 旧名 | 新名 | 备注 |
|---|---|---|
| 记忆 / memory | 事实 `fact` | 旧 `memories` 表退场 |
| 结论 | 判断 `conclusion` | 同一概念，统一叫"判断" |
| 规则 / 画像 / 待修 | **状态**：规则=active、画像=active、待修=candidate | 这三者不再是三种类型，而是"生没生效" |
| 原则候选 | `candidate` + `type_name=原则` | 不再有专门字段 |
| 候选 / 待核 | `candidate` | 合并成一个状态 |
| 线索 / 主题 / episode | 线索 `thread` | 不再引入 episode 这个词 |
| 片段 / turn_pair | 轮 `turn` | `turn_pairs` 只读退场 |

## 7. 可携带（跨工具）

**携带 = 导出契约**，不是注入节奏。换宿主/换工具后仍然存在的只有一份文件：

```
profile.md / profile.json
  画像（≤8 条，带维度）
  规则（触发 + 动作）
  承诺（未兑现 + 已兑现）
  偏好（明确的、用户确认过的）
不含：对话原文、推理过程、情绪样本
```

- **每轮注入**是另一件事：画像常驻、记忆按需、handoff 每会话一次；
- 导出的东西必须**人可读、可编辑**，否则"换工具不用重讲"做不到。
