电视下线前，产线工人要在里面做几件事：

| 类别 | 具体 |
|---|---|
| **校准** | 屏幕白平衡、背光、色彩曲线；音频增益、喇叭相位 |
| **写入** | 序列号、MAC 地址、地区码、HDCP 密钥、频道制式 |
| **检测** | 按键、遥控接收头、屏、喇叭逐项自检 |
| **配置** | 选机型、选销售区域、开关某些系统功能 |

售后维修也用它——修完恢复出厂、清 EEPROM、查故障码。

**`To Fac` 这种标志位就在里面**：`U` = 用户模式（Normal），`M` = 工厂/工程模式（Manufacture）。海信靠它决定「要不要放开发者选项出来」——所以我们进去把它改成 `M`，原生设置的入口才开。

## 别和「商场模式」混了

这俩名字像，完全是两回事：

| | 工厂菜单 | 商场模式 |
|---|---|---|
| 给谁 | 产线工人、售后工程师 | 门店里的顾客 |
| 干什么 | 校准、写参数、开调试开关 | 循环播宣传片、亮度锁最高、设置项灰掉 |
| 怎么进 | 按键组合（声音平衡 + 1969） | 设置菜单里直接有 |
| 你该不该关 | **改完该退就退** | **该关**，家用留着纯碍事 |

你现在**商场模式还开着**——那是零售演示锁，建议关掉：`设置 → 系统 → 高级系统设置 → 商场模式 → 关`。

## 为什么我们碰它

因为海信把 ADB 开关藏在里面了，正常菜单够不着：

```
路线 A  工厂菜单 → 选项 → ADB 开关 → 开        ← 你走的应该是这条
路线 B  工厂菜单 → 选项 → To Fac → U 改 M → 重启
        → 本机信息 → 连按菜单 → 原生设置 → 版本号 → 开发者选项 → USB 调试
```

**这是绕过限制，不是正常使用方式**——海信没打算让用户碰到它。

## ⚠️ 里面的红线

工厂菜单里**混着能毁数据的选项**：

```
清空数据 / 工厂复位 / 调屏幕参数 / 写密钥
```

**只改你进来的那一个项，改完立刻退出。** 尤其别碰「工厂复位」——那会把电视清到出厂状态，序列号和密钥也可能被重写。

另外有资料提到**反复改 `To Fac` 可能让 USB 口失灵**，得重置电视才恢复。所以这类开关**改一次就够，别来回试**。

## 为什么没触发：HTTPS 是硬门槛

Chrome 要求 PWA 必须在**安全上下文**里才能安装，而你访问的是：

| PWA 组件 | 在 http 内网下 |
|---|---|
| `beforeinstallprompt` | ❌ 不触发 |
| **Service Worker**（`sw.js`） | ❌ 注册不了（SW 同样要求安全上下文） |
| 独立窗口（standalone） | ❌ 做不到 |
